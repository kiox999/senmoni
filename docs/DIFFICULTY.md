# 難易度（difficulty）の基準

全問に `difficulty: "easy" | "medium" | "hard"` を付ける。新しく作る問題にも必ず付ける。
UIには表示しない裏設定で、段位認定の出題配分に使う。

| 区分 | 目安 | 例 |
|---|---|---|
| easy | 1ステップで答えられる基本知識。定義・正常値・定番の第一選択・典型像そのままの診断 | 9の法則、GCSの評価項目、典型的な腸重積の検査 |
| medium | 2ステップ。診断したうえで次の検査・治療を選ぶ／典型からやや外れる。標準的な専門医レベル | 臨床像から敗血症性ショックと判断し、次の昇圧薬を選ぶ |
| hard | スコア・分類の計算や閾値、ガイドラインの細かい数値・時間・推奨、例外・禁忌・ピットフォール、紛らわしい鑑別、正解3つ以上の複数解答 | Parkland公式の計算、driving pressure、ベルリン定義、TG18重症度、Kernohan切痕 |

- 配分の目安：easy 3割・medium 5割・hard 2割（科目全体で）
- 迷ったら medium
- 段位認定：hard の割合は `RANKS[].h` で決まる。hard 以外の枠では、5級〜2級は easy を、六段以上は medium を優先して出題する
- 今後の予定：Firestoreに問題ごとの正答率を集計し、回答数がたまった問題は実際の正答率で補正する
