# リマインド通知（プッシュ通知）の設定

その日まだ1問も解いていない人の端末へ、本人が決めた時刻に通知を送る機能です。
**下の3つを済ませるまで、アプリに設定欄は表示されず、通知も送られません**（これまでどおり動きます）。

## しくみ

- 端末側：最初の画面（科目を選ぶ画面）の「リマインド通知」でオンにすると、端末の宛先と時刻を Firestore の `pushSubs` に保存します。クラウド同期へのログインが必要です。
- 「今日は解いた」の記録：ログイン中に問題を解くと、1日1回だけ `pushAct/<uid>` に日付を書きます（別の端末で解いた日も通知しないため）。
- 送信側：GitHub Actions（`.github/workflows/push.yml`）が1時間ごとに `tools/send_push.mjs` を実行し、時刻になった・その日まだ解いていない端末へ送ります。

## 1. 通知用の鍵を作って貼る

1. [Firebaseコンソール](https://console.firebase.google.com/) → プロジェクト `senmoni-board` → 歯車 →「プロジェクトの設定」→「Cloud Messaging」タブ
2. 「ウェブプッシュ証明書」の「鍵ペアを生成」を押す
3. 表示された長い文字列（鍵ペア）を、`firebase-config.js` の `vapidKey: ""` の `""` の中に貼ってコミットする（公開してよい値です）

## 2. Firestore のルールを更新する

Firebaseコンソール → Firestore Database →「ルール」に、このリポジトリの `firestore.rules` の中身を丸ごと貼り直して「公開」。
（`pushSubs` と `pushAct` の規則が増えています。貼り直すまで、通知をオンにしようとすると「設定できませんでした」になります）

## 3. 送信用の秘密鍵を GitHub に登録する

1. Firebaseコンソール →「プロジェクトの設定」→「サービス アカウント」タブ →「新しい秘密鍵を生成」→ JSONファイルがダウンロードされる
2. GitHub のこのリポジトリ → Settings → Secrets and variables → Actions →「New repository secret」
   - Name: `FIREBASE_SERVICE_ACCOUNT`
   - Secret: ダウンロードしたJSONファイルの中身を丸ごと貼る
3. ダウンロードしたJSONファイルは削除する

**このJSONは管理者用の鍵です。リポジトリにコミットしたり、人に渡したりしないでください**（`vapidKey` と違い、公開してはいけません）。

## 動作確認

1. アプリを開き直し、ログインして「リマインド通知」をオンにする（時刻は何時でもよい）
2. GitHub → Actions →「リマインド通知の送信」→ 最新の実行のログに「対象 n 件 / 送信 n …」と出ていれば動いています
3. すぐ試したいときは、時刻を「いまの時」に合わせて（例：14時台なら 14:00）、その日まだ解いていない状態で「Run workflow」を押す

## 知っておくこと

- **iPhone・iPad**：Safari で開いただけでは使えません。共有メニューの「ホーム画面に追加」で追加したアプリから開いてオンにします（iOS 16.4 以降）。
- **時刻のずれ**：GitHub の定期実行は遅れたり、間引かれたりします（数十分〜数時間）。決めた時刻から3時間以内に実行された回で送り、それを過ぎた日は送りません。
- **端末ごとの設定**：スマホとPCの両方に届けたいときは、それぞれでオンにします。
- **ログアウト**すると、その端末の通知は自動でオフになります。
- GitHub は、リポジトリに60日間更新がないと定期実行を止めます（Actions の画面に再開ボタンが出ます）。
- 費用：通知の送信は無料です。Firestore の読み書きもごく少量です。
